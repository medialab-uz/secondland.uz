# SecondLend — оптимизированный лендинг

## Перед публикацией
1. В `config.js` уже указана ссылка Telegram: `https://t.me/+NQiPcYQBdbk0MGIy`.
2. Замените `hello@secondlend.uz` на действующий контакт.
3. Проверьте `privacy.html` и адаптируйте её под реальные процессы.
4. После публикации можно добавить URL сайта в canonical и Open Graph.

## Что реализовано
- Адаптивный лендинг для смартфонов, планшетов и компьютеров.
- Telegram CTA в шапке, на первом экране, в каждой карточке преимуществ и шага, карточках-примерах, финальном блоке и подвале.
- Meta Pixel `1701137841542210`: PageView и Lead (клик по Telegram), только после согласия на маркетинговые cookies.
- Демонстрационные тексты карточек явно обозначены как примеры, а не реальные отзывы.
- Политика конфиденциальности, favicon, robots.txt.
- Удалён неиспользуемый тяжёлый файл концепта из deploy-пакета.

## GitHub Pages
Загрузите содержимое папки `SecondLend` в корень репозитория. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

`Lead` означает клик по ссылке Telegram после согласия на маркетинговые cookies, а не подтверждённую подписку.
