# Secondland — Telegram clothing marketplace landing page

Responsive Russian-language landing page for a Telegram community where people can sell clothes they no longer wear and find pre-loved clothing at attractive prices.

## Files
- `index.html` — page structure and copy
- `style.css` — responsive visual design
- `script.js` — lightweight client-side script
- `images/poster.png` — promotional poster (if included)

## Publish with GitHub Pages
1. Upload all files and the `images` folder to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then press **Save**.
5. Wait for GitHub Pages to finish publishing.
